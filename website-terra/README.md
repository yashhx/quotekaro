# TrackRakho Terra site

This is a private marketing-site concept. It is deliberately outside `public/`, so it is not part of the deployed TrackRakho application or `trackrakho.com`.

Run it locally from the repository root:

```bash
node website-terra/serve.mjs
```

Then open [http://localhost:4180](http://localhost:4180).

Pages:

- `/` — overview
- `/machining.html` — machine job shops
- `/scrap.html` — scrap businesses
- `/platform.html` — product platform and Tally connection
- `/pricing.html` — one-plan pricing

The site is static HTML/CSS/JS. It has no tracking, backend, authentication, or deployment wiring.
